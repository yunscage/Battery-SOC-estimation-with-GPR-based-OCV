Please run the "Run_main" in the "Algorithm Source Code" folder to check the result.

The 4th and 5th lines of the "Run_main" code are used to select the conditions.

4: cnt_degc = 2; % 1 2 4 5
5: cnt_j = 1; % 1 UDDS; 3 LA92; 4 US06

The variable "cnt_degc" can be selected from (1, 2, 4, 5), which represents the temperature at -20, -10, 10, and 25 respectively.

The variable "cnt_j" can be selected from 1 to 12, which represents the 12 driving cycle conditions.


For the OCV data, the ".mat" file named with "C20DisCh" provid the C/20 current rate discharge and charge voltage curve and relevant data. You can click the file and run "View_Data" to see the OCV result.

Original Source of the data set: "Kollmeyer, Phillip J.; Skells, Michael, 2023, "Multi Temperature Li-ion Battery Data - SB LiMotive 5Ah", https://doi.org/10.5683/SP3/LFPKAS"
